# Звуки игры

Код: `IdleDwarfsGame.Client/src/services/soundService/`:
- `soundCatalog.ts` — каталог ключей (канал, громкость, частота повтора, запасной звук);
- `SoundService.ts` — воспроизведение и музыка;
- `uiSounds.ts` — клики и наведение для всего интерфейса;
- `sounds.ts` — синтез боевых звуков, пока нет файлов.

## Как добавить звук

1. Назовите файл **как ключ** из таблиц ниже и положите в `IdleDwarfsGame.Client/src/assets/sounds/`, в любую подпапку
   (для порядка: `ui/`, `battle/`, `music/`). Пример: `assets/sounds/ui/ui_click.mp3`.
2. Форматы: `.mp3`, `.ogg`, `.wav`, `.webm`. Если у одного звука есть несколько форматов, браузер выберет поддерживаемый
   (порядок: ogg → webm → mp3 → wav).
3. **Варианты** одного звука играют случайно, чтобы частые звуки не приедались: `ui_click.mp3`, `ui_click-2.mp3`, `ui_click-3.mp3`.
4. Перезапустите `npm run serve`: файлы собираются при сборке. Если имя файла не совпадает ни с одним ключом,
   в консоли браузера появится предупреждение `[sounds] Файлы без ключа…`.

Если файла нет, сервис идёт по цепочке запасных ключей (колонка «Запасной»). У боевых звуков в конце цепочки синтез,
поэтому арена звучит и без файлов. У остальных ключей без файла тишина.

Громкость в настройках аккаунта (у каждого канала своя): **Музыка**, **Интерфейс** (канал `ui`), **Бой** (канал `sfx`).
Громкость отдельного звука, разброс высоты тона и ограничение частоты повтора задаются в `soundCatalog.ts`.

Советы по файлам: короткие звуки — без тишины в начале (иначе звук запаздывает от клика), нормализуйте громкость
(около −14…−16 LUFS для эффектов), моно для интерфейса, 44.1/48 кГц. В игру — MP3 (или OGG), WAV держите исходниками
вне `src/` (например, в `IdleDwarfsGame.Client/sounds-src/`): WAV в 10 раз тяжелее, а все короткие звуки грузятся заранее.

### Музыкальные лупы

Если конец трека не совпадает с началом сэмпл в сэмпл, на каждом повторе слышен щелчок. Склейка стыка кроссфейдом
и кодирование в OGG + MP3 одной командой:

```
cd IdleDwarfsGame.Client
npm run sounds:loop -- sounds-src/music/<исходник>.wav music_town      # третий аргумент — кроссфейд, с (по умолчанию 0.75)
```

Скрипт (`tools/sound-loop.js`) печатает скачок на стыке до и после и кладёт `music/<ключ>.ogg` и `music/<ключ>.mp3`.
OGG повторяется без паузы (Chrome, Firefox, Edge), MP3 — запасной для браузеров без OGG.
Музыка играет через Web Audio: буфер повторяется с точностью до сэмпла, без паузы, которая есть у `<audio loop>`.

## Разметка кнопок

Клик и наведение звучат сами у всех кнопок, ссылок, вкладок и элементов с курсором-рукой. Изменить звук можно атрибутом:

| Атрибут | Что делает |
|---|---|
| `data-sound="ui_click_primary"` | свой звук клика (любой ключ каталога) — главные кнопки: «В бой», «Купить», «Открыть» |
| `data-sound="none"` | без звука клика и наведения — у действия свой звук (крестик окна, удар киркой, карты сундука) |
| `data-sound-hover="ui_hover_card"` | свой звук наведения (любой ключ); работает и на некликабельном — карточки |
| `data-sound-hover="none"` | без звука наведения |
| `data-hover-id="town-mine"` | элементы с одним id звучат при наведении как одно целое (здание и его плашка) |

Кнопки звучат `ui_click_button`, остальное кликабельное (карточки, плитки, здания) — `ui_click`.
Звук наведения `ui_hover_card` стоит на карточках: `HeroCard`, `ItemTile`, `GemTile`, `AbilityTile` (способности
и пассивки), сундуки склада (`InventoryChests`) и почты (`ChestTile`), карточки спуска (`DelveRewardCard`,
`DelveRelicCard`, `DelveSlotCard`, `DelveRelicSlot`). `ui_hover_button` — на всех гем-кнопках (`GemButton`)
и кнопках меню (`NavButton`). `ui_hover_town` — на зданиях города (`TownView`) и на карточках боя с превью арены: этапы кампании
и башни (`FightPreviewList`), боссы гильдии (`GuildBosses`), мировой босс (`WorldBossPanel`), соперники PvP
(`PvpModal`), узлы карты спуска (`DelveNodeSign`). Только когда в бой можно идти: закрытый этап, побеждённый босс,
удар на перезарядке, PvP без отряда, недоступный узел молчат (`data-sound-hover="none"`).
Вернулись мышью с кнопки внутри карточки на саму карточку — повторно она не звучит.
Вкладки (`role="tab"`) звучат `ui_tab`, флажки — `ui_toggle_on`/`ui_toggle_off`, ползунки — `ui_slider`,
неактивные кнопки (`disabled`) — `ui_click_disabled`.

## Новый звук

1. Ключ в `soundCatalog.ts`: канал, длительность, при необходимости `volume`, `throttle`, `pitch`, `fallback`.
2. Вызов `soundService.play('ключ')` в месте события. Если звук должен играть после успешного запроса:
   `api().then(soundService.played('ключ'))`.
3. Строка в эту таблицу.
